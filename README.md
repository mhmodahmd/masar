# مسار — منصة إدارة المشاريع الخيرية (نسخة عرض)

صفحة تعريفية ونسخة تجريبية تفاعلية من منصة **مسار** لإدارة المشاريع الخيرية: طلبات الدعم والاعتماد، وتوثيق المتبرعين، والحوالات والصرف، وأرصدة الحسابات، وتقارير الإنجاز.

- `index.html`: الصفحة التعريفية.
- `app/`: النسخة التجريبية. تعمل كاملة داخل المتصفح بلا خادم، ببيانات **وهمية**، وما يُضاف فيها يُحفظ في متصفح الزائر فقط.

## حسابات التجربة

كلمة المرور لكل الحسابات: `Masar@2026!`

| الدور | اسم المستخدم |
|---|---|
| المدير العام | `manager` |
| مدير النظام | `admin` |
| المحاسب | `accountant` |
| موظف المشاريع | `projects` |
| السكرتير | `secretary` |
| جهة منفذة | `partner` |

روابط مباشرة: `app/?as=accountant&page=transfers` تدخل بالدور وتفتح الصفحة.
